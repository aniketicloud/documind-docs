# Documind

**Documind** is a Next.js application for document-centric chat: sign in, upload documents to S3-compatible storage (RustFS), run async ingest into Qdrant, and stream Gemini answers grounded in **indexed** files you attach to a message.

This site documents the **application repository** (`documind`), not this docs package itself.

## What you can do in the app

- **Auth** — email/password via Better Auth
- **Multi-chat** — `/new` starts a chat; `/c/[id]` continues it; history in the sidebar
- **Streaming RAG** — Gemini answers over retrieved chunks (text files fully supported today)
- **Documents** — upload, list, download, delete; ingest statuses; ownership enforced
- **Settings** — General (name/email) and Account (logout)
- **Redis demo** — simple key/value CRUD against Docker Redis
- **Infrastructure** — Postgres, Redis, RustFS, Qdrant (compose)

## Quick start (app)

```bash
cd ../documind
cp example.env .env
# set GEMINI_API_KEY (and optional ZAI_API_KEY) in .env
docker compose up -d   # includes pdf-extract + ingest-worker
npm install
npm run db:push
npm run dev            # only app terminal needed
```

Set `GEMINI_API_KEY` in `.env` (see [Environment](/docs/guide/environment)).  
Worker and PDF extract run inside Compose — see [PDF extract](/docs/guide/pdf-extract).

App: [http://localhost:3000](http://localhost:3000)  
These docs (local): [http://localhost:3001/docs](http://localhost:3001/docs)
