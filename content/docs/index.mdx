# Documind

**Documind** is a Next.js application for document-centric chat: sign in, upload text documents (PDF, Word, Excel, Markdown, etc.) to S3-compatible storage (RustFS), manage files, and hold multiple conversations with document attachments.

This site documents the **application repository** (`documind`), not this docs package itself.

## What you can do in the app

- **Auth** — email/password via Better Auth
- **Multi-chat** — `/new` starts a chat; `/c/[id]` continues it; history in the sidebar
- **Documents** — upload, list, download, delete; ownership enforced
- **Settings** — General (name/email) and Account (logout)
- **Redis demo** — simple key/value CRUD against Docker Redis
- **Infrastructure** — Postgres, Redis, RustFS, Qdrant (compose)

## Quick start (app)

```bash
cd ../documind
cp example.env .env
docker compose up -d
npm install
npm run db:push
npm run dev
# second terminal — required for document status "indexed"
npm run worker:ingest
```

App: [http://localhost:3000](http://localhost:3000)  
These docs (local): [http://localhost:3001/docs](http://localhost:3001/docs)

New to ingest / the worker? Read [Document ingest (Option A)](/docs/guide/document-ingest).
