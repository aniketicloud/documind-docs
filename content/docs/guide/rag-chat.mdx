Plain-language record of **document-grounded chat** and product rules.

## The simple picture

```text
1. UPLOAD     →  Save the file in RustFS (fast, browser → S3)
2. INGEST     →  Docker worker extracts text, chunks, embeds → Qdrant
3. CHAT / AI  →  User asks; app retrieves chunks; model streams an answer
```

| Step | User-visible | System |
|------|--------------|--------|
| **Upload** | Chip “done”; file on **My documents** | Presigned PUT to RustFS; Postgres row |
| **Ingest** | Badge `processing` → `indexed` | Compose **`ingest-worker`** + **`pdf-extract`** for PDFs |
| **Chat** | Live streaming reply | **Selected** (checked) **indexed** docs from the chat panel |

## What we built

### Ingest

When Compose **`ingest-worker`** claims a job it:

1. Downloads the object from RustFS  
2. Extracts text:  
   - **`.txt` / `.md` / `.csv`** — Node  
   - **`.pdf`** — HTTP to **`pdf-extract`** (PyMuPDF; **OCR** if scanned and `ocr=auto`)  
3. Chunks → embeds with **`gemini-embedding-2`** → Qdrant  
4. Marks **`indexed`** or **`failed`**

### Chat (streaming RAG)

| Endpoint | Role |
|----------|------|
| `POST /api/chats/stream` | Create chat + user message → stream → save |
| `POST /api/chats/:id/messages/stream` | Append + stream (`documentIds` = panel selection) |

### Product rules

| Rule | Why |
|------|-----|
| **Indexed-only RAG** | Honest status; no fake answers from half-processed files |
| **Documents panel** | Pins stay until removed; checkboxes choose files for the next answer |
| **Collapsible panel** | More room for messages when collapsed |
| **Upload ≠ AI** | Upload can finish while status is still Processing… |
| **Streaming** | Live tokens in the UI |
| **Multi-model** | Z.AI GLM + Gemini Interactions; default often GLM |
| **Sources footer** | Trust: show which doc chunks grounded each answer |

### Sources footer (citations)

When RAG retrieves chunks for a turn, Documind stores them on the **assistant** message and shows a **Sources** row under the reply:

| Field | Meaning |
|-------|---------|
| Document name | File that contributed the chunk |
| `§N` | Chunk index within that file |
| Score | Similarity from Qdrant (shown as % when 0–1) |
| Hover / title | Short snippet of the retrieved text |

**How it works**

1. `retrieveContext` finds up to 6 chunks in Qdrant  
2. `chunksToSources` builds a compact citation list (no full chunk dump)  
3. Stream still sends **plain text tokens** (unchanged client stream protocol)  
4. `saveAssistantMessage` persists `sources` as JSONB on `chat_messages`  
5. UI reloads messages (or handoff after `/new`) and renders the footer  

General chat (no docs selected) and “not indexed yet” answers have **no** sources row.

## What “indexed” means for chat

| File type | After successful ingest |
|-----------|-------------------------|
| `.txt`, `.md`, `.csv` | Vectors → usable for RAG |
| **`.docx`** | Mammoth → RAG if text found; else **`failed`** |
| **Text-based PDF** | Fast native extract → RAG |
| **Scanned PDF** | OCR (Tesseract) → RAG if text found; else **`failed`** |
| Other office binaries | May be storage-only until XLSX / etc. extract |

## How to run the full path

```bash
docker compose up -d   # includes ingest-worker + pdf-extract
npm run dev
```

### Happy path

1. Upload a short **text PDF**, **`.docx`**, or `.txt` in **My documents**  
2. Wait for **`indexed`**  
3. New chat → add files (panel above messages) → **check** the ones to use  
4. Wait for **Indexed** if needed → ask a question → answer **streams**

## Code map (app repo)

| Path | Responsibility |
|------|----------------|
| `lib/text-extract.ts` | Text + async PDF + DOCX (Mammoth) extract |
| `lib/pdf-extract-client.ts` | HTTP client for pdf-extract service |
| `lib/gemini.ts` | Embeddings + Interactions stream |
| `lib/qdrant.ts` | Collection, upsert, search |
| `lib/rag.ts` | Retrieve + stream grounded answer + `chunksToSources` |
| `lib/chats.ts` | `saveAssistantMessage({ sources })`, load on `getChatMessages` |
| `chat_messages.sources` | JSONB citation array on assistant rows |
| `components/chat-workspace.tsx` | Sources footer under assistant bubbles |
| Compose `ingest-worker` | Long-running claim loop |
| Compose `pdf-extract` | PDF → text |
