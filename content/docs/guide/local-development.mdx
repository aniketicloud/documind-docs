## Recommended terminals

1. **Docker** — `docker compose up -d`  
   Starts Postgres, Redis, Qdrant, RustFS, **pdf-extract**, and **ingest-worker**  
2. **App** — `npm run dev` in `documind`  
3. **Docs** (optional) — `npm run dev` in `documind-docs` on port **3001**  

**Do not** start a host ingest process for normal work — Compose already runs **`ingest-worker`**.  

Without Compose, uploads may still save files, but documents stay **`processing`**.  
PDF + worker: [PDF extract](/docs/guide/pdf-extract) · [Document ingest](/docs/guide/document-ingest).

## Ports cheat sheet

| Port | Service |
|------|---------|
| 3000 | Documind Next.js app |
| 3001 | Documind docs (this site, local) |
| 5433 | Postgres |
| 6379 | Redis |
| 9000 | RustFS S3 API |
| 9001 | RustFS console (`rustfsadmin` / `rustfsadmin`) |
| 6335 | Qdrant HTTP |
| 8090 | PDF extract (PyMuPDF service) |

## Typical feature loop

1. Branch in `documind`  
2. Change API / UI / schema  
3. `npm run typecheck`  
4. Manual test (auth, chat, upload, redis)  
5. Update docs in `documind-docs` when behavior or env changes  

## UI stack notes

- **shadcn/ui** (Radix Nova style), Tailwind CSS 4  
- Chat primitives: MessageScroller, Message, Bubble, Attachment, Marker  
- Shared patterns: Spinner, Empty, AlertDialog  

See [UI conventions](/docs/development/ui).

## Agent / AI coding

`documind/AGENTS.md` reminds agents to read Next.js 16 docs under `node_modules/next/dist/docs/` before changing framework APIs.

## Full AI path

1. Set `GEMINI_API_KEY` in `.env`  
2. `docker compose up -d` (Qdrant, **pdf-extract**, **ingest-worker**, …)  
3. `npm run dev`  
4. Upload a `.txt` or **PDF** → appears in chat documents panel → **Indexed** → ask  

See [RAG chat](/docs/guide/rag-chat) and [PDF extract](/docs/guide/pdf-extract).
