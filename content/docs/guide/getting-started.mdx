## Prerequisites

- **Node.js** 20+ (22+ recommended)
- **npm** (or compatible package manager)
- **Docker Desktop** (or Docker Engine + Compose) for Postgres, Redis, RustFS, Qdrant
- Git

## Clone and open the app

```bash
cd C:\Users\Aniket\Documents\GitHub
cd documind
```

## First-time setup

1. Copy environment file and set secrets:

```bash
cp example.env .env
```

Edit `.env`: set `BETTER_AUTH_SECRET` and **`GEMINI_API_KEY`** (Google AI Studio). Never commit real keys.

2. Start infrastructure:

```bash
docker compose up -d
```

3. Install dependencies and push the schema:

```bash
npm install
npm run db:push
```

4. Start the app **and** the ingest worker (two terminals):

```bash
npm run dev
```

```bash
npm run worker:ingest
```

5. Open [http://localhost:3000](http://localhost:3000), create an account, and try **New chat**.

## What “done” looks like

| Check | Expected |
|-------|----------|
| App | Marketing home + login/signup |
| After login | Redirect to `/new` |
| Docker | Postgres `:5433`, Redis `:6379`, RustFS `:9000`/`:9001`, Qdrant `:6335` |
| Documents | Upload a `.txt` under **My documents** → status **`indexed`** |
| Chat | Attach that indexed file → ask a question → **streamed** answer |
| Redis demo | CRUD on `/redis` |

## Why two Node processes?

- **`npm run dev`** — UI and APIs (including streaming chat)  
- **`npm run worker:ingest`** — background extract/embed into Qdrant  

Without the worker, files never become RAG-ready. Details: [Document ingest](/docs/guide/document-ingest) · [RAG chat](/docs/guide/rag-chat).
