## Overview

```bash
docker compose up -d
docker compose ps
docker compose logs -f redis
```

## Postgres

- Host port **5433** (avoids clashing with a local Postgres on 5432)
- Volume: `pgdata`

## Redis

- Port **6379**
- AOF enabled
- **`--protected-mode no`** so the host app can connect via Docker port publish  
  (Docker NAT is not “loopback” from Redis’s point of view; protected mode would deny Node clients)
- Volume: `redisdata`
- Used for the **Redis demo** API and the **ingest job queue** (`documind:ingest:queue`)

## RustFS

- S3-compatible storage: **9000** (API), **9001** (console)
- Default credentials: `rustfsadmin` / `rustfsadmin`
- Volume: `rustfs_data`
- App creates bucket `documind` and sets CORS for browser uploads

## Qdrant

- Ports **6335** (HTTP), **6336**
- Volume: `qdrant_storage`
- **In use for RAG:** stores **embedding vectors** (lists of numbers) for document chunks + original chunk text in payload
- App env: `QDRANT_URL=http://127.0.0.1:6335` (host maps to container `6333`)
- Collection vector **size must match** `GEMINI_EMBED_DIMENSIONS` (default 768). If you change embed model/dims, re-ingest — see [Embeddings & Qdrant](/docs/guide/embeddings-and-qdrant)
