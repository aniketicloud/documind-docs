## 1. Closure

**Q: What is a closure?**

**Answer:**  
A closure is created when an inner function can access variables of the outer function.  
This works even after the outer function has finished running.  
It is very useful for data privacy.

**Example:**
```js
function outer() {
  let count = 0;
  return function inner() {
    count++;
    return count;
  }
}
const counter = outer();
console.log(counter()); // 1
console.log(counter()); // 2
```

## 2. Destructuring

**Q: What is destructuring?**

**Answer:**  
Destructuring means taking values from an array or object and storing them in variables in a simple way.  
It makes the code cleaner and shorter.

**Example:**
```js
const user = { name: "Aniket", age: 28 };
const { name, age } = user;
console.log(name); // Aniket
```

## 3. Object spread

**Q: What is the spread operator?**

**Answer:**  
The spread operator is used to copy or merge arrays and objects.  
We use three dots `...` for this.  
It is very common in modern JavaScript.

**Example:**
```js
const obj1 = { a: 1 };
const obj2 = { ...obj1, b: 2 };
console.log(obj2); // { a: 1, b: 2 }
```

## 4. this keyword

**Q: What is the `this` keyword?**

**Answer:**  
`this` refers to the current object.  
In a method, `this` points to the object that owns the method.  
Its value depends on how the function is called.

**Example:**
```js
const person = {
  name: "Aniket",
  greet() {
    console.log(this.name);
  }
};
person.greet(); // Aniket
```

## 5. call, apply, bind

**Q: What is call, apply and bind?**

**Answer:**  
These methods are used to set the value of `this`.  
call and apply run the function immediately.  
bind returns a new function with the bound `this`.

**Example:**
```js
function greet() {
  console.log(this.name);
}
const user = { name: "Aniket" };
greet.call(user); // Aniket
```

## 6. Promise

**Q: What is a Promise?**

**Answer:**  
A Promise is used to handle asynchronous operations.  
It has three states: pending, fulfilled and rejected.  
We use `.then()` for success and `.catch()` for error.

**Example:**
```js
const promise = new Promise((resolve, reject) => {
  resolve("Success");
});
promise.then(result => console.log(result));
```

## 7. async & await

**Q: What is async and await?**

**Answer:**  
async and await make asynchronous code look like normal synchronous code.  
await waits for a Promise to complete.  
It makes the code much cleaner than using `.then()`.

**Example:**
```js
async function getData() {
  const result = await Promise.resolve("Data received");
  console.log(result);
}
getData();
```

## 8. IIFE

**Q: What is IIFE?**

**Answer:**  
IIFE means Immediately Invoked Function Expression.  
It is a function that runs as soon as it is defined.  
It is useful to create a private scope.

**Example:**
```js
(function () {
  console.log("I run immediately");
})();
```

## 9. Scope

**Q: What is scope?**

**Answer:**  
Scope means the area where a variable can be accessed.  
There is global scope and local scope.  
Variables declared inside a function are local to that function.

**Example:**
```js
let globalVar = "I am global";

function test() {
  let localVar = "I am local";
}
```

## 10. Class vs Object

**Q: What is the difference between class and object?**

**Answer:**  
A class is a blueprint.  
An object is a real instance created from that class.  
We use the `new` keyword to create an object from a class.

**Example:**
```js
class Person {
  constructor(name) {
    this.name = name;
  }
}
const p1 = new Person("Aniket");
```

## 11. Prototype

**Q: What is prototype in JavaScript?**

**Answer:**  
Every object in JavaScript has a prototype.  
The prototype is used to share properties and methods.  
This is the base of inheritance in JavaScript.

**Example:**
```js
function Person(name) {
  this.name = name;
}
Person.prototype.greet = function () {
  console.log("Hello " + this.name);
};
```

## 12. Object Inheritance

**Q: How does inheritance work in JavaScript?**

**Answer:**  
JavaScript uses prototypal inheritance.  
One object can inherit properties and methods from another object.  
We can also use the `class` and `extends` keywords.

**Example:**
```js
class Animal {
  speak() {
    console.log("Animal sound");
  }
}
class Dog extends Animal {}
const d = new Dog();
d.speak(); // Animal sound
```

## 13. Design Pattern

**Q: What are design patterns?**

**Answer:**  
Design patterns are ready-made solutions for common problems in code.  
They help us write clean and reusable code.  
Common patterns are Module pattern, Singleton and Observer.
