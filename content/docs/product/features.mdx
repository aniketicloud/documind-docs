## Marketing site

- Public landing page (`/`) with feature/pricing-style sections  
- Header/footer shell; theme toggle (light/dark)  
- Signed-in users redirect to **`/new`**

## Authentication

- Sign up / sign in with email and password (Better Auth)  
- Session cookies; protected app shell under `app/(app)`  

See [Authentication](/docs/product/auth).

## Multi-chat + document Q&A

- **New chat** → `/new` (empty composer)  
- First send creates a chat, **streams** a Gemini answer, navigates to `/c/[id]`  
- **Recent** sidebar: rename, delete  
- **RAG rules:** **checked + indexed** docs in the collapsible chat documents panel  
- **Searchable today:** `.txt` / `.md` / `.csv`, **text PDFs**, and **scanned PDFs** (local OCR)  

See [Chat](/docs/product/chat) and [RAG chat guide](/docs/guide/rag-chat).

## Documents

- Upload from **My documents** and from chat  
- List, download (presigned GET), delete  
- Owner-only isolation  
- Ingest: `processing` → `indexed` / `failed` (Docker **`ingest-worker`** + **`pdf-extract`**)  
- Allowed types: PDF, Word, Excel, CSV, TXT, Markdown, RTF, ODT/ODS  
- **RAG-ready:** text files + PDFs (native or OCR) when status is **indexed**  

See [Documents](/docs/product/documents), [Document ingest](/docs/guide/document-ingest), [PDF extract](/docs/guide/pdf-extract).

## Settings

- User menu → **Settings** dialog  
- **General** — name & email (read-only)  
- **Account** — log out  

See [Settings](/docs/product/settings).

## Redis demo

- Page `/redis` + sidebar link  
- Create / read / update / delete string keys under `documind:kv:`  

## Dashboard

- Legacy shadcn dashboard demo still exists at `/dashboard`  
- Not the primary product entry point after multi-chat
