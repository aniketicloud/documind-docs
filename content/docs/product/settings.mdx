## Settings dialog

Opened from the user menu → **Settings**.

| Nav | Content |
|-----|---------|
| **General** | Name and email (read-only inputs) |
| **Account** | Log out |

Claude-style layout: left sidebar nav + right content panel.

## Theme

- Light / dark via `next-themes`  
- Icon toggle (no system option in the button)  
- Optional `d` key hotkey when not typing
