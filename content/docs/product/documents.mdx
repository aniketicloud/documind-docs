## User surfaces

- **My documents** (`/documents`) — upload, list, download, delete, ingest status, retry  
- **Chat composer** — paperclip (upload now) and library picker (**indexed** docs for RAG)  

## Upload pipeline

1. `POST /api/documents/presign` — validate type/size, insert `pending` row, return presigned **PUT** URL  
2. Browser **PUT**s file to RustFS  
3. `POST /api/documents/confirm` — HEAD object, mark ready, **enqueue ingest job**  

Keys look like:

```text
users/{userId}/{documentId}/{safeFilename}
```

## Allowed types

Defined in `lib/document-types.ts`:

- PDF: `.pdf`  
- Word: `.doc`, `.docx`  
- Excel: `.xls`, `.xlsx`, `.csv`  
- Text: `.txt`, `.md`, `.markdown`, `.rtf`  
- OpenDocument: `.odt`, `.ods`  

Max size: **50MB**. Images/audio/video/executables rejected.

## Security

- List/get/download/delete always filter by **session user id**  
- Other users get **404** (no existence leak)  
- Storage keys are not returned to the client on presign  
- Download uses short-lived presigned GET after ownership check  

## Upload vs ingest vs chat

| Concept | Meaning |
|---------|---------|
| **Upload** | Bytes in RustFS; chat chip “done” |
| **Ingest** | Worker prepares the file (text extract + embeddings when possible) |
| **Indexed** | Ingest succeeded; text files can be used for RAG |
| **Chat panel** | Files in this chat; checkboxes choose which are sent as `documentIds` for the next answer |

- **My documents** shows full ingest badges (`processing` → `indexed` / `failed`).  
- **Chat documents panel** shows status + select/deselect + remove from chat (collapsible).  

**Why split them:** uploads must stay fast; AI prep is slow and retriable. See [Document ingest](/docs/guide/document-ingest).

## Parsing / RAG (current)

| Type | Ingest behavior |
|------|-----------------|
| `.txt`, `.md`, `.csv` | Node extract → chunk → Gemini embed → Qdrant |
| **Text-based PDF** | Docker **pdf-extract** (PyMuPDF, fast) → embed → RAG when **`indexed`** |
| **Scanned / image PDF** | Same service runs **OCR** (`auto`) → RAG if text found; else **`failed`** |
| Word / Excel (binary) | Storage OK; full DOCX extract planned later |

Chat uses **retrieved chunks** from **selected + indexed** panel docs. See [Chat](/docs/product/chat), [RAG chat](/docs/guide/rag-chat), and [PDF extract](/docs/guide/pdf-extract).

Ingest requires **`docker compose up -d`** (services `ingest-worker` + `pdf-extract`).
